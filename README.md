## 製品概要
### 背景(製品開発のきっかけ、課題等）
### 製品説明（具体的な製品の説明）
学生のレポート作成支援をする際に、PDFファイルを、引用しやすいまた、新たにPDFファイルから文書を作成しやすいようにすることが可能にする機能が搭載されています。
[サンプル動画](./movePDFACTER.mp4)



### 特長
#### 1. 特長1
##### テキスト抽出
PDFファイルからテキスト（文字列）を抽出して、各文ごとにコピーしやすいように振り分けれます。
#### 2. 特長2
##### ヘッダー、フッター除去
論文などのPDFファイルからヘッダー、フッターを取り除けることができ、PDFのページをまたがってコピーする際に大いに役立ちます。
#### 3. 特長3
##### リアルタイム文字カウント
レポートを作成する際に、文字数指定が大抵の場合存在すると思いますが、この機能を使用することで選択した文字をリアルタイムで文字数をカウントできレポート作成に大いに役立ちます。
### 解決出来ること

### 今後の展望
* 参考文献の自動作成（実装済みだが精度が甘い）
* 化学式などにおける上付き下付き文字の情報の保持
* 注釈の上付きをコピーされないようにする。
* PDFの文中の「表1」などを押したとき、表1に飛ぶ 
* PDF中の参考文献をクリックしたときにその論文に飛ぶ
### 注力したこと（こだわり等）
* 様々なPDFのフォーマットに対応できるプログラム
* ヘッダーフッターの試行を重ねた除去
